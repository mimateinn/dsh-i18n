Устойчивый плагин интернационализации для DeepSeek Harness Web UI. Версия 0.2.0 регистрирует **20 локалей** из одного реестра, сохраняя при этом существующую интеграцию клиентского ModuleLoader в DSH, сервис локалей, миграцию предпочтений и поведение рантайм-фолбэка.

## Локали

繁體中文（香港、台灣）, 日本語, 한국어, Français, Deutsch, Español, Português (Brasil), Italiano, Русский, Українська, Polski, Nederlands, Türkçe, العربية, हिन्दी, Bahasa Indonesia, Tiếng Việt, ไทย, и Svenska.

- Традиционные китайские локали (zh-HK, zh-TW) выполняют фолбэк из встроенных словарей упрощённого китайского через существующий конвертер символов.
- Арабская локаль задаёт язык и направление документа `ar` / `rtl`; остальные управляемые локали используют `ltr`.
- Непереведённые значения, не относящиеся к китайскому, возвращаются к английскому.

## Возможности

- Добавляет все 20 локалей в **Settings → General → Language** вместе со встроенными 中文 / English.
- Тщательно выверенные переводы для каждого официального пространства имён локалей (по 715 строк), сделанные с английской базовой версии.
- Рантайм-фолбэк: новые/обновлённые/сторонние строки возвращаются к английскому (или конвертации упрощённого→традиционного китайского для zh-HK/zh-TW), поэтому обновления вышестоящего UI и других плагинов покрываются без повторного перевода каждого языка.
- Языковое предпочтение сохраняется в браузерном `localStorage`; устойчиво к перезагрузке.
- **Иммерсивный перевод**: когда активна некитайская локаль, длинный английский текст (описания в маркетплейсе плагинов, сторонний UI, текст ошибок) автоматически переводится на ваш язык через вашу настроенную модель — с кэшированием и идемпотентностью, поэтому повторные рендеры React не конфликтуют с ним. Язык по умолчанию (en/zh) не затрагивается; традиционный китайский сохраняет встроенную конвертацию упрощённого→традиционного вместо обращения к модели.
- Нулевое вмешательство: чистый клиентский плагин, без изменений вышестоящих пакетов, тихая деградация при отсутствии сервиса локалей.

## Установка

Установите в профиль, который реально загружает ваш хост, и закрепите коммит:

```bash
dsh plugin --profile <active-profile> add github:mimateinn/dsh-i18n#<commit>
```

Для DSH Desktop активным профилем является значение `active` в `%APPDATA%/DSH Desktop/profile-selection/state.json` (обычно `desktop`). Шим для каждого профиля `host-commands/<profile>/bin/dsh.cmd` вшивает собственное имя профиля в команду, поэтому запуск шима `web` устанавливает плагин в профиль `web`, даже когда Desktop показывает `desktop` — установка проходит успешно, но плагин никогда не загружается. Явно передавайте `--profile`, чтобы быть уверенным.

Пути установки Market в DSH Desktop принимают только точную опубликованную версию npm, поэтому спецификацию GitHub нужно проводить через встроенный терминал `dsh plugin add`, который передаёт спецификатор в pnpm без валидации.

Перезапустите хост, затем выберите язык в **Settings → General → Language**. Удаление выполняется командой `dsh plugin --profile <active-profile> remove dsh-i18n`.

## Пайплайн сопровождения

Реестр локалей — это `scripts/locales.mjs`. Данные переводов остаются в `src/<locale>/`; сгенерированный браузерный код — `lib/client.js`.

```bash
npm run i18n:check     # file, namespace/key, stale, placeholder, empty, English-residue, Simplified-residue parity
npm run i18n:build     # assemble registry locales into lib/client.js
npm test               # check + build + converter verification + runtime harness

node scripts/extract.mjs <installed-dsh-path>
```

Извлечение принимает установленный корень DSH, каталог его пакета `@deepseek-ai` или путь к распакованному десктопному приложению.

## Публикация

Пакет npm включает рантайм-компоненты, сгенерированный клиент, данные локалей и реестр локалей. Репозиторий исходников: https://github.com/mimateinn/dsh-i18n

## Безопасность и конфиденциальность

- Плагин сам не выполняет сетевых вызовов, не имеет телеметрии и читает/пишет только два ключа браузерного localStorage: идентификатор выбранной локали и переопределение модели перевода.
- Иммерсивный перевод выполняется через встроенный LLM-сервис DSH (вашу настроенную модель), а не через сторонний API. Он срабатывает только для длинного английского текста при активной некитайской локали; язык по умолчанию никогда не отправляется на перевод.
- Нет доступа к файловой системе, нет обработки учётных данных.
